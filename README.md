# Google Photos Album Landing Page

Static single-page site that links to Google Photos albums. Update the album cards in `index.html` and push to GitHub Pages to publish.

## Usage
1. Replace the album titles, locations, years, and URLs in `index.html`.
2. Commit and push to your repository.
3. Enable **GitHub Pages** for the repository, using the `work` branch (or `main` if renamed) with the `/` (root) folder.

The included `style.css` provides a lightweight layout that is easy to customize later.
